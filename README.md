# BookingTicketCinema-SDN-Assignment

## Run backend
1. Install MongoDB and make sure it is running.
2. `cd backend`
3. Copy `.env.example` to `.env`.
4. `npm install`
5. `npm run seed`
6. `npm run dev`

## Run frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`
4. Open the Vite URL.

## Demo accounts

## Implemented CE190006 scope
- Book Movie Ticket
- Add Food & Drink
- Reserve Seat (10-minute hold)
- Payment Process
- Apply Member Point
- Payment via VNPay (demo flow; real merchant credentials can be plugged in later)
- Create Account
- Update Account Status
- Adjust Member Points
